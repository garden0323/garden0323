## Featured Project

### MUSE

**나만의 취향을 전시하고, 다른 사람의 세계를 탐색하는 SNS**

MUSE는 기존 SNS의 피드 중심 구조에서 벗어나,
사용자마다 자신만의 디지털 전시관을 만들고
취향과 개성을 표현할 수 있는 소셜 플랫폼입니다.

| 항목 | 내용 |
| --- | --- |
| 프로젝트 | MUSE |
| 유형 | Social Networking Service |
| 역할 | 기획 · 디자인 · 개발 |
| 진행 상태 | Beta Development |

#### Key Features

- 개인 전시관 생성 및 커스터마이징
- 전시관 탐색 및 사용자 간 소셜 네트워킹
- 팔로우 / 팔로잉 기반 관계 시스템
- 친구 전용 공간 및 공개 범위 설정

#### Tech & Tools

`Cloudflare` `D1` `R2` `AI-assisted Development`
